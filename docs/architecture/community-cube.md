# Публичный общий куб Supcube

`/community-cube` показывает демо. `/community-cube/live` читает данные из API и
позволяет разместить обработанный автограф, который уже прошёл модерацию.
На главной ссылка на публичную версию появляется при
`COMMUNITY_CUBE_PUBLICATION_ENABLED=true` в окружении Web. Данные и действия
публикации разрешает API со своей настройкой `COMMUNITY_CUBE_PUBLICATION_ENABLED`.
Обе настройки по умолчанию выключены. API требует включённого first-use и
доступных актуальных документов для активации. Перед включением на staging
или production нужно завершить согласование публикации в EGO-75 и EGO-110.

В бете у аккаунта один активный автограф в общем кубе. Гость может смотреть
открытые места. Владелец выбирает номер свободного места после одобрения
автографа и подтверждает его публичное размещение. Предварительное
резервирование не используется. Публикация в общем кубе не меняет стены
авторов и бесплатные или платные размещения на них.

PostgreSQL назначает текущее поколение. Вместимость первых четырёх поколений
равна 24, 144, 864 и 5 184. При заполнении переход сохраняет номера мест, так
что предыдущий куб помещается на первую грань следующего. После снятия
автографа поколение сохраняется, а место снова доступно. Четвёртое поколение
задаёт предел беты. Уникальные ограничения и транзакция исключают двойное
занятие. Повтор запроса с тем же идентификатором возвращает исходное активное
размещение. Запрос к устаревшему поколению или занятому месту требует свежего
выбора.

У каждого места открывается только проверенный производный PNG. API сверяет
состояние публикации и доказательства модерации, отдаёт медиа без кэширования
и не раскрывает ключ хранилища или оригинальный файл. Если аккаунт приостановлен,
место может оставаться занятым, но PNG перестаёт выдаваться. После снятия
размещения или удаления аккаунта место освобождается. Во время отключения
публикации свой автограф по-прежнему можно снять на `/community-cube/live`.

Для приёмки проверить сохранение после перезагрузки, гонку за ячейку,
повтор запроса, смену поколения, недоступность чужого автографа и отзыв медиа.
Документы тестового контура остаются только в изолированном окружении приёмки.
